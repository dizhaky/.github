A new push to a PR cancels the older run of the same workflow. Pushes to `main` group by `run_id` and are never cancelled. Push runs are never cancelled, even on feature branches: a push secret scan covers only `before..after`, so cancelling one would leave its commits unscanned. The reusable `reusable-*.yml` workflows are untouched: they inherit the caller's `github.workflow`, so a group there would cancel the caller.
