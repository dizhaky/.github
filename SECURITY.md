# Security Policy

## Reporting

If you discover a security issue in a private repository under **dizhaky**, report it directly to the repository owner rather than opening a public issue.

## Automated protections

Organization defaults (via [dizhaky/.github](https://github.com/dizhaky/.github)) include:

- **Dependabot** version and security updates on active code repositories
- **Gitleaks** secret scanning on push and pull requests
- **Branch protection** on default branches for production-oriented repos

## Response expectations

- Critical issues: acknowledge within 48 hours
- High issues: triage within 1 week
- Dependency alerts: addressed via Dependabot PRs or manual bumps on a rolling basis
