# Obsidian Vault First (CANON)

**Read the Obsidian vault before any non-trivial task** — never start from session memory alone. It holds people, projects, decisions, GitHub/infra ops and personal context. Vault: `$OBSIDIAN_VAULT` (Mac: `~/Dev/obsidian-vault`). Skill: `obsidian-vault-manager`.

1. Find the matching project in `Projects/` (GitHub work: `Projects/Tech/GitHub Ops/` plus the repo's folder under `Projects/Tech/`).
2. Read its `PROJECT.md`, `TASKS.md`, `DECISIONS.md`, and today's `Daily Notes/YYYY-MM-DD.md` (ET) for in-flight work.
3. After the work: update `TASKS.md` / `PROJECT.md` (`updated:` frontmatter) and append to the Daily Note's `## Operations Diary`.

History goes in the owning repo's `docs/system-log/`; never create `SESSION-LOGS/` (DAN-1283). Use wikilinks for internal references.
