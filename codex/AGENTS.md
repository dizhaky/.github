# Codex Agent Rules

## Operating defaults (CANON — all tasks)

Read and apply `rules/CODING-RULES.md` § Operating defaults before substantive work. Read relevant policy sections once per task/context; reuse them until scope or source changes.
Canonical fallback outside this checkout: `~/Dev/dotfiles/rules/`. Local-first requires working runtime evidence; a local shell is not local inference. Explicit read-only, plan-only and no-ship scope wins.

## Work and safety

Follow `rules/CODING-RULES.md` for Karpathy discipline, task-scoped autonomy, token discipline, discovery, dispatch and completion. State assumptions, make the smallest useful deliverable, verify before closing, and continue authorized work without routine permission questions. Credential rotation requires confirmation with the exact target named; preserve all protected-action safeguards and unrelated work. Never bypass hooks, signing, required checks or review.

For non-trivial actionable work, read `rules/LINEAR-WORKFLOW.md` (fallback `~/Dev/dotfiles/rules/LINEAR-WORKFLOW.md`): reuse issues/projects, one Claim-group decision owner, native dependencies, agent lease/check-out, Blocked + one Waiting reason, verified Done and TASKS.md mirror. Q&A and trivial edits are exempt. Tracking does not authorize unrelated work or writes during a read-only task.

Read task-relevant vault context per `rules/OBSIDIAN-VAULT-FIRST.md`; use `obsidian-vault-manager` for vault work. Memory Gateway receipts follow CODING-RULES rule 12; unchanged facts can reuse receipts and exempt tasks report N/A.

## Verification and output

Substantial work (3+ observable outcomes): write GATES.md before implementation and use `unlazy`; record every gate's evidence or explicit ABANDON. Define done, snapshot baseline, independently verify real results, parse JSON as JSON, fix and recheck before closing. Record Method, Scope, Before, After and PASS/FAIL in a `## QC Verification` block. Details: `~/.claude/refs/QC-CORE.md`.
Before user-file moves/deletes/renames or OneDrive/Graph reorgs, read `~/Dev/dotfiles/.claude/refs/QC-CONSTITUTION.md`; preserve manifests and verify every leaf.

Output: `~/.claude/refs/OUTPUT-FORMAT.md` (status emoji, terse, ≤8 lines by default, bold Next). Report actual completion or the narrow blocker; recommendations do not expand authorized scope.
